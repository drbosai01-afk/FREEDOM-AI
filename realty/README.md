# FREEDOM REALTY — этап 1

Мобильный локальный MVP рабочего блокнота для агента по недвижимости.

## Запуск
Откройте `realty/index.html` в современном браузере (Chrome на Android либо desktop).

## Реализовано
- CRUD объектов недвижимости, клиентов и показов
- Поиск по каждому разделу
- Сохранение через localStorage
- Проверка ссылки объявления и HTML-экранирование пользовательского ввода
- Резервное копирование данных в JSON

## Ограничения
- Данные живут только в конкретном браузере: без авторизации, облачной синхронизации и совместной работы
- Не подключены Bitrix24, ИИ, живые прайсы или платежи
- Не используйте реальные персональные данные до внедрения контроля доступа, безопасного сервера и правовых оснований обработки
