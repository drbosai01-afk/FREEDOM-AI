# FREEDOM 0.2 — подключение ИИ

Это тестовая версия, а не безопасный релиз для повседневного использования. Ранее Google Play Protect показывал предупреждение для debug APK — причина не установлена. До проверки APK не вводите личные данные и ключи на основном телефоне.

## Что реализовано

- Кнопка **«Подключить ИИ / отключить»** для HTTPS-совместимого API Chat Completions.
- Адрес по умолчанию: `https://api.openai.com/v1/chat/completions`.
- Модель по умолчанию: `gpt-4o-mini`. Можно изменить на другую, если провайдер поддерживает этот формат.
- Прямой запрос с пользовательским API-ключом и явным согласием на отправку текста; входящие ответы отображаются в чате.
- Ограниченные по времени запросы и сообщения об ошибках без раскрытия ключа.
- API-ключ и история находятся только в памяти приложения, не сохраняются между запусками.
- Кнопка **«Отключить»** удаляет текущий ключ и историю из памяти приложения (не отзывает ключ у провайдера).
- Голосовая кнопка запускает системное распознавание речи; файлы не передаются ИИ.

## Ограничения

- Это **сетевой** ИИ. Поддержка локальных моделей, безопасное хранилище ключей и полноценные инструменты управления телефоном ещё не реализованы.
- API-ключ оплачивается и оформляется у провайдера отдельно: подписка ChatGPT Plus не даёт доступ к API.
- Приложение отправляет весь текущий диалог выбранному провайдеру; провайдер может обрабатывать и хранить эти данные по своей политике.
- Не вводите ключ в неизвестный HTTPS endpoint. Нет сертификации сервера по списку доверенных провайдеров.
- Успешная сборка доказывает только, что компиляция и автоматические тесты прошли; она **не доказывает**, что APK безопасен или что живой API-запрос уже протестирован.

## План безопасности до установки на основной телефон

1. Проверить установочный APK, его подпись, состав зависимостей и разрешения.
2. Разобрать предупреждение Play Protect; не отключать защиту.
3. Проверить реальный сетевой запрос на отдельном тестовом устройстве с одноразовым ключом и ограниченным бюджетом.
4. Исправить результаты аудита и выпускать только проверенный APK.

Связанные требования: `SECURITY.md`, `docs/AI_INTEGRATION_0_2.md`.
