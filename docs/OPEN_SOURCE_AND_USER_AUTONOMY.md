# FREEDOM: open source and user autonomy

FREEDOM is intended to be an open-source, user-controlled assistant.

## Freedom of expression
- Discuss ordinary topics, opinions, personal circumstances and creative ideas without hidden ideological or viewpoint-based filtering.
- Prefer candid, accurate answers over paternalism or unnecessary refusals.
- Distinguish between discussing a subject and autonomously acting on devices, accounts or people.
- Make any safety-related restriction explicit and explain the reason where possible.

## Non-negotiable boundaries
- "Uncensored" does not mean unauthorized device access, covert monitoring, data exfiltration, bypassing Android protections, or unrestricted harmful autonomous actions.
- Preserve the human-safety, informed-consent and immutable-policy requirements of SECURITY.md.
- For external actions, require scoped authorization and per-action confirmation for consequential operations.

## Open-source delivery
- Publish application and core orchestration source, build scripts, tests and permission logic in the repository.
- Document dependencies and licenses; choose an OSI-approved license before public distribution.
- Never commit secrets, personal user data, third-party API keys or APK signing keys.
- If a model or speech engine is proprietary, clearly label that component: open-source app code is not automatically an open-weight AI model.
- Support user-chosen providers, including on-device/open-weight models when practical.
- Ensure conversation storage and deletion are under user control.
